GUÍA DE ARCHIVOS PRINCIPALES DEL PROYECTO OLLAMA_RAG

Documento general de apoyo:

- Explicacion_completa_codigo_OLLAMA_RAG.pdf
  Explica de forma detallada el funcionamiento completo del proyecto, la arquitectura,
  el flujo de ejecución y el papel de cada archivo principal.

Orden de revisión sugerido:

1. Explicacion_completa_codigo_OLLAMA_RAG.pdf
   - Documento de referencia general.
   - Resume la estructura completa del proyecto y explica el código en detalle.

2. README.md
   - Resume la instalación, la ejecución y la estructura general del proyecto.
   - Permite entender rápidamente cómo está organizada la entrega.

3. clean_json.py
   - Script de limpieza del dataset.
   - Descarga o lee el dataset, filtra registros no útiles y genera el archivo limpio.

4. rag_utils.py
   - Archivo central de utilidades compartidas.
   - Contiene la lógica de limpieza, clasificación por temas, deduplicación,
     selección balanceada de registros, fragmentación en chunks y utilidades del sistema.

5. train_clean.json
   - Resultado del proceso de limpieza.
   - Permite comprobar directamente cómo ha quedado el dataset final.

6. index_data.py
   - Script de indexación.
   - Genera embeddings con Ollama e indexa el contenido limpio en la base vectorial Chroma.

7. app.py
   - Aplicación principal del proyecto.
   - Incluye el pipeline RAG, el retriever, la memoria conversacional,
     el prompt del sistema y la interfaz Gradio.

8. requirements.txt
   - Lista de dependencias necesarias para ejecutar el proyecto.

9. screenshots/01-inicio.png
10. screenshots/02-respuesta-con-contexto.png
11. screenshots/03-sin-informacion-suficiente.png
   - Capturas del proyecto en funcionamiento.
   - Muestran la interfaz y distintos comportamientos del sistema.

12. Explicacion_completa_codigo_OLLAMA_RAG.html
   - Versión HTML del documento explicativo completo.

Resumen por entregables principales:

- Script de limpieza: clean_json.py
- Script de indexación: index_data.py
- Aplicación principal: app.py
- Dependencias: requirements.txt
- Dataset limpio: train_clean.json
- Documentación: README.md
